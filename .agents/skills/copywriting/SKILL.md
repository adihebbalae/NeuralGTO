# Copywriting for NeuralGTO

## When to Use This Skill

Use this skill when the user wants to:
- Write or rewrite copy for landing pages, homepage, or section headers
- Create email campaigns or outreach sequences
- Write ad copy or social media posts
- Improve existing messaging
- Create CTAs or button text

---

## Core Framework

### 1. Read Product Context First
Before writing any copy, pull context from `product-marketing-context.md`:
- **Positioning:** "GTO Explained. Not Memorized."
- **Primary audience:** Aspiring tournament players, cash game regulars, coaches
- **Differentiation:** Free + Explained + Simple = Professional GTO without the price tag
- **Tone:** Precision & density (technical, data-heavy, minimal fluff)

### 2. Copy Architecture for NeuralGTO

**Landing Page Structure:**
1. **Hero Headline** — Problem + Solution in one line
   - "Game Theory Optimal poker. Explained, not memorized."
   - "Professional GTO solving. At zero cost."
2. **Subheadline** — Emotional or benefit-driven
   - "Analyze hands like a pro. Understand why frequencies exist. Learn when to exploit."
3. **Social Proof** — Credibility (coaches using it, community citations)
4. **Feature Callout** — 3 core differentiators
5. **CTA** — Single, action-oriented button
   - Primary: "Analyze a Hand"
   - Secondary: "Read GTO 101"
6. **Proof Section** — Real hand examples
7. **FAQ** — Address skepticism (won't PioSOLVER be better? Is this legal to use?)

## Copywriting Principles for Poker

### Avoid
- ❌ Sales hyperbole ("Become a poker pro overnight")
- ❌ Jargon without explanation (even to experts, context helps)
- ❌ Language suggesting real-money playing aid (compliance risk)
- ❌ Comparison put-downs ("Other solvers are overpriced and bad")

### Embrace
- ✅ Specificity ("Analyze heads-up hands under $100 pots in seconds")
- ✅ Transparency ("Free. Open-source. No signups.")
- ✅ Education focus ("Study tool, not playing aid")
- ✅ Poker domain knowledge (speak the language, but explain terms)
- ✅ Intellectual honesty ("GTO tells you optimal play; you decide when to deviate")

## Copywriting Checklist

Before submitting copy, verify:
- [ ] Headline is benefit-driven or clarity-driven, not vague
- [ ] Subheadline reinforces the unique angle (explaining, not just solving)
- [ ] Copy avoids hype about "winning more" or "becoming a pro"
- [ ] All poker jargon used is accurate and explained (or context implies understanding)
- [ ] CTAs are single, action-oriented verbs ("Analyze," "Learn," "Explore")
- [ ] Tone matches domain: technical, precise, helpful expert
- [ ] No claim about legality or real-money play is made (study tool only)
- [ ] Copy is concise — poker players value efficiency
