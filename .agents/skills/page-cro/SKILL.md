## Core CRO Framework for Poker Tool

### Understanding NeuralGTO's Conversion Goals

**Primary (Study/Launch):**
- User completes first hand analysis
- User returns for second analysis
- User engages with guides or educational content

**Secondary (Future Monetization):**
- User signs up for email/newsletter
- Coach recommends tool to students
- User shares hand analysis

**Tertiary (Community):**
- User posts analysis to Reddit/Discord
- Link shares in poker communities

### Conversion Funnel

```
Landing Page
    ↓
Value Prop Clarity (Is this for me? Do I understand it?)
    ↓
CTA Clarity (What do I click?)
    ↓
Analyze Hand Tool (First experience)
    ↓
Value Delivery (Does the explanation make sense?)
    ↓
Second Use (Does it feel worth my time?)
    ↓
Retention (Do I come back?)
```

### 2. CTA Optimization

**Current (likely weak):**
- "Get Started" → Generic, no benefit signaling
- "Learn More" → Passive, implies reading, not doing
- "Use the Tool" → Confusing, unclear

**Optimized variants to test:**

| Page Section | Current CTA | Optimized CTA | Why |
|---|---|---|---|
| Hero | "Get Started" | "Analyze a Hand" | Specific action, immediate value |
| Features | "Learn More" | "See the Difference" or "Try Free Now" | Benefit-driven or urgency |
| FAQ | "Sign Up" | "Analyze a Hand" (no form) | Remove friction |
| Social Proof | "Read Case Study" | "Analyze This Hand" (example) | Interactive, not passive |

**CTA Button Design:**
- Primary color: Emerald-400 (EV-positive signal)
- Text: White, bold, 16px+
- Padding: 12px 32px (large, clickable target)
- Border: None (don't use outline buttons for primary CTA)
- Hover state: Darker emerald with subtle shadow

### 6. FAQ Section Optimization

**High-intent questions (address objections):**
- "How accurate is this vs. PioSOLVER?"
- "Is it legal to use this while playing?"
- "Can it analyze multi-way pots?"
- "Do I need to understand GTO to use it?"
- "Is there a limit to how many hands I can analyze?"

**Order by intent:** Put objection-removers first, curiosity questions last

## A/B Testing Roadmap

**Phase 1 (High-confidence tests — run simultaneously):**
1. Button text: "Analyze a Hand" vs. "Try Free Now"
2. Hero subheadline: Problem focus vs. Benefit focus
3. Trust signal: "Free. No signup." vs. "Open source. Privacy-first."

**Phase 2 (After Phase 1 winner):**
1. Feature section layout: Cards vs. Interactive example
2. CTA color: Current emerald vs. Amber (neutral frequency signal)
3. FAQ order: Objections first vs. Curiosity first

**Phase 3 (Targeting and messaging):**
1. Personalized headlines by intent (tournament player vs. coach)
2. Social proof variants (player count vs. coach testimonials)
3. Multi-stage CTAs (first CTA = "See Example" → "Analyze Now")

## Conversion Optimization Checklist

- [ ] Hero CTA is visible without scrolling
- [ ] CTA button is high-contrast, large (36px+ height), and obvious
- [ ] Value prop is clear in 1-2 subheadings (no jargon barrier)
- [ ] Trust signal or social proof appears above the fold
- [ ] "Analyze a Hand" tool is accessible from every page (navigation or persistent CTA)
- [ ] FAQ addresses the 3 biggest objections (cost, accuracy, legality)
- [ ] Page has no distracting secondary CTAs competing with primary
- [ ] Mobile experience is streamlined (tool is usable on mobile)
- [ ] Load time is <2 seconds (if analyzing hands in browser)
- [ ] Example hand is prominent and clear (visual proof of value)

## Field Notes for Poker Learners

**Key insight:** Poker players are optimizers. They care about:
- Clarity over copy length (respect their time)
- Accuracy over enthusiasm (wrong analysis tanks trust forever)
- Proof over promises ("Show me the hand output, not the sales pitch")

**Messaging angle that resonates:**
> "No hype. Just better strategy."
