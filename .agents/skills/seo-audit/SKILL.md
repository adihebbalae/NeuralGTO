## SEO Audit Checklist

### On-Page SEO

**Title Tag** (50–60 characters)
- Template: "[Primary Keyword]" + "[Secondary benefit]"
- Examples:
  - ❌ "NeuralGTO — Poker Tool"
  - ✅ "GTO Poker Explained: Free Hand Analysis Tool"
  - ✅ "How to Analyze Poker Hands with GTO Strategy"
- Rule: Include primary keyword; stay under 60 chars; benefit-driven

**Meta Description** (150–160 characters)
- Template: "[Benefit]" + "[Unique angle]" + "[CTA]"
- Example:
  - "Analyze poker hands in English. Get GTO strategy with the reasoning behind it. Learn why frequencies exist. Free, no signup."
- Rule: Include primary keyword; actionable; make reader want to click

**H1 Tag** (1 per page)
- Should match or closely align with title tag
- Example: "GTO Poker Strategy Explained (And When to Exploit)"
- Rule: Clear, includes primary keyword, benefit-driven

**H2/H3 Hierarchy** (logical sub-sections)
- Use to break content into scannable chunks
- Include secondary keywords when relevant
- Example structure:
  ```
  H1: GTO Poker Explained
    H2: What is Game Theory Optimal?
    H2: Why Frequencies Matter
      H3: Equity Realization in GTO
      H3: Blocker Effects on Strategy
    H2: How to Analyze Your Hands
  ```

**Keyword Integration**
- Primary keyword appears in: title, H1, first 100 words, throughout body (2–3% density)
- Secondary keywords in H2/H3 subheadings
- Semantic keywords (related terms) naturally in body
- Avoid keyword stuffing; prioritize readability

**Internal Links**
- Link to related guides (e.g., "GTO 101" → "How to Read Solver Output")
- Link from blog to product page (tool)
- Anchor text should be descriptive, not "click here"
- Examples:
  - ✅ "Learn more about blocker logic in poker strategy"
  - ❌ "Click here for more info"

**External Links**
- Link to authoritative poker sources (Upswing, Run It Once, etc.)
- Avoid low-authority poker sites
- Use `rel="external"` for outbound links

---

### Technical SEO

**Page Speed**
- Target: <2 seconds on 4G
- Test: Google PageSpeed Insights, GTmetrix
- Common issues: Large images, unoptimized resources, slow backend

**Mobile-Friendly**
- Responsive design (works on mobile/tablet)
- Touch-friendly buttons (44px+ tap target)
- Readable text (16px+ on mobile)
- Test: Google Mobile-Friendly Test

**Structure & Navigation**
- Breadcrumb navigation (Home > Blog > "GTO Explained")
- Clear sitemap (XML sitemap.xml)
- Logical URL structure:
  - ✅ `/guides/gto-poker-explained`
  - ❌ `/blog/123456`

**Schema Markup** (Structured Data)
- Article schema for blog posts
- FAQPage schema for FAQ sections
- Breadcrumb schema for navigation
- Organization schema on homepage
- Test: Rich Results Test tool

**Accessibility**
- Valid HTML (use W3C validator)
- Image alt tags (describe content, not "image1.jpg")
- Proper color contrast (WCAG AA minimum)
- Heading hierarchy (no skipping H1 → H4)

## Content SEO Recommendations

### Blog Posts & Guides

**Template: SEO-Optimized Blog Post**
```
Title: [Primary keyword]" + "[Benefit]" (max 60 chars)
Meta: [Benefit] + [Unique angle] + [CTA] (150–160 chars)

H1: [Catchy headline matching title]

Intro Paragraph (100–150 words):
  - Hook: Problem or question (audience pain point)
  - Agitate: Why it matters for poker players
  - Solve: Preview what the post covers

Table of Contents: (if >2,500 words)
  - Helps UX and creates internal anchor links

H2 Section 1 (500–700 words): Foundational content
  - Answer the "what" question
  - Include primary keyword once naturally
  - Link to related content

H2 Section 2 (500–700 words): Practical application
  - Answer the "how" or "why" question
  - Include secondary keywords in H3s
  - Example or case study

H2 Section 3 (300–500 words): Advanced or nuance
  - Address objections
  - Cover edge cases
  - Link to related skills

CTA Section:
  - Next step (read another guide, use the tool, join community)
  - Low-friction (no form required for first CTA)

Related Content: (internal links)
  - 3–5 related blog posts or guides
  - Use descriptive anchor text
```

## AI Search Optimization (AEO / LLM Optimization)

### Target AI Engines: ChatGPT, Claude, Perplexity, Google Gemini

**How LLMs cite sources:**
- LLMs prioritize authoritative educational content
- They prefer clear explanations over sales copy
- Comprehensive guides rank higher than product pages

**Optimization tactics:**
1. **Write comprehensive guides** (2,500+ words) on GTO concepts
2. **Use clear structure:** H1 → H2 → H3 with logical flow
3. **Define terms explicitly** (LLMs favor content that teaches)
4. **Include examples and case studies** (LLMs prefer concrete explanations)
5. **Link strategically:** Connect related concepts
6. **Optimize for "cited by" queries:** "What sources explain GTO?"

**Example: "GTO Poker Explained" article likely to be cited by LLMs because:**
- ✅ Comprehensive (covers what, why, how)
- ✅ Clear structure (easy to parse)
- ✅ Educational focus (not sales-y)
- ✅ Authoritative (backed by real tool & citations)
- ✅ Unique angle (explains *why*, not just frequencies)

## Audit Workflow

**Step 1: Baseline Audit**
Run each page through:
- Google PageSpeed Insights (performance, SEO score)
- Mobile-Friendly Test (mobile responsiveness)
- Lighthouse Audit (accessibility, SEO, best practices)
- Schema.org Rich Results Test (structured data)

**Step 2: On-Page Review**
- Check each page: title, meta, H1, content length, keyword usage
- Verify internal link structure
- Review external link quality and anchor text
- Check image alt tags and sizing

**Step 3: Content Assessment**
- Is the primary intent keyword in title, H1, intro, body?
- Are secondary keywords reflected in H2/H3?
- Is the content comprehensive (2,000+ words for "how-to")?
- Are there examples, data, or case studies?
- Does the page answer the searcher's question?

**Step 4: Competitive Check**
- Find top 5 search results for each primary keyword
- Compare: length, structure, depth, comprehensiveness
- Identify gaps NeuralGTO can fill

**Step 5: Recommendations**
- List quick wins (title/meta rewrites, internal links)
- Recommend content gaps (missing blog posts)
- Suggest structure improvements

## Common SEO Mistakes for Poker Tools

❌ **Avoid:**
- Long keyword slugs ("/free-online-poker-game-analyzer-gto-solver-strategy-tool")
- Keyword stuffing ("GTO poker, GTO poker strategy, GTO poker explained, GTO poker...")
- Thin content (<500 words) on popular topics
- Flash or JavaScript-heavy interfaces (hard for search engines)
- Broken links to other poker resources
- Duplicate answers across multiple pages (canonicalize or consolidate)

✅ **Do:**
- Honor search intent (information searchers want guides, not product pages)
- Update old content (refresh blog posts every 6 months)
- Cite sources (link to TexasSolver, poker theory, solver comparison)
- Use schema.org markup generously
- Build backlinks through community (Reddit, Discord, coaching sites)
